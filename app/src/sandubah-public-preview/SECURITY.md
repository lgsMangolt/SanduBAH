# Segurança e privacidade

Esta distribuição é uma prévia estática sem backend, autenticação ou acesso ao computador.

Não abra issues públicas contendo credenciais, tokens, anexos pessoais, dados de clientes ou conversas. Não envie informações sensíveis para testar a demonstração.

Para relatar uma vulnerabilidade, use a opção **Report a vulnerability** da aba Security do GitHub, quando disponível. Se não houver um canal privado habilitado, abra apenas uma solicitação genérica de contato, sem prova de exploração nem dados sensíveis.

O aplicativo desktop completo não é distribuído neste repositório. Uma futura distribuição requer revisão própria de dependências, isolamento, permissões e tratamento de dados.
